# Audience Information Architecture

## Public audience profiles

Every account has an optional, compact public identity at `/@handle`. It exposes only display name, handle, avatar, optional biography, join month, and whether the account also has active creator capabilities. Email, wallet data, viewing activity, notifications, sessions, identity records, and followed creators are never included in the public response. Users control audience-profile visibility from Account Profile; active creator presentation remains public under the creator lifecycle rules. Blocking and reporting require explicit authenticated actions. Audience-to-audience following is intentionally deferred; Following continues to mean following creators.

`/discover` is the canonical public browsing route. It contains only content-oriented surfaces: live followed creators when present, Live now, temporary language/tag filters, calculated Trending when meaningful, Popular tags, and recommended creators when live inventory is limited. Legacy `/tags` and `/categories` paths are replaced with `/discover` while preserving query parameters.

Account-owned content has stable routes: `/account/following`, `/account/activity`, `/account/notifications`, `/account/profile`, `/account/security`, `/account/sessions`, `/account/preferences`, and `/account/wallet`. Visiting these pages is read-only until the user explicitly saves, marks, follows/unfollows, changes a reminder, or performs another named command. Saved discovery preferences are distinct from temporary `/discover?q=&languages=&tag=` URL filters.

The global search form submits to `/discover?q=...` from public rooms, creator profiles, and account pages. Public server filtering remains authoritative and excludes drafts and restricted creator resources.

Offline rooms are informational surfaces, not live sessions. Audience clients do not join the realtime room, contribute presence, load current live chat, or receive a composer. The API independently refuses offline joins and chat sends. Offline community chat and archived-chat presentation are deferred.

Notification reads are side-effect free. Schedule reminders are generated by an idempotent server background poller and delivered through the existing user realtime channel; opening Discover or Notifications never creates a reminder.

Community classification is deprecated. Migration 029 disables selection/rendering while retaining historical database rows until a reviewed production inventory supports removal. “New Creators” may later return only as a system-generated collection, never as creator-selected Community identity data.
